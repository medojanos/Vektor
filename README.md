# Vektor

Vektor is a web application designed for individuals to plan and optimize their personal travel routes. It helps users create efficient multi-stop journeys, saving time and effort.

## Features

*   Intuitive route planning interface
*   Multi-stop itinerary creation
*   Optimized route suggestions
*   Save and manage your routes

## Installation

```bash
git clone https://github.com/medojanos/Vektor.git
cd Vektor
npm install
npm start
```

## Quick Start

1.  Navigate to [Vektor](https://vektor.meadowhub.net/) in your web browser.
2.  Click "New Route" to begin planning.
3.  Add your starting point and subsequent destinations.
4.  Vektor will automatically optimize the order of your stops.
